# Coleccionista 3D

Juego corto para correr dentro de Blender. WASD o las flechas mueven al jugador, R reinicia y ESC sale.

## Cómo abrirlo

1. Abre Blender.
2. Ve a la pestaña Scripting.
3. Abre `juego_basico.py`.
4. Pulsa Run Script.
5. Haz clic en la vista 3D para que tome el teclado.

`abrir_juego.bat` abre el archivo en el editor.
